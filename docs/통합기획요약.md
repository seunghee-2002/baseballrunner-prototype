# Baseball Action Runner — 통합 기획 요약

팀장이 원한 게임의 방향과 기획안의 핵심 규칙을 **하나로 합친 논의용 문서**다.
규칙마다 **왜 이렇게 정했는지**를 짧게 붙였다.

* 규칙만 빠르게 볼 때: [`기획요약.md`](기획요약.md)
* 아이디어가 나온 과정: [`아이디어대화요약.md`](아이디어대화요약.md)
* 설계 원문: [`기획안.md`](../기획안.md)

---

## 1. 우리가 만들려는 게임

> **타격으로 루타의 가능성을 만들고, 주루 액션으로 그 가능성을 실현하는 야구 액션 게임.**

| 항목 | 방향 |
| --- | --- |
| 장르 | 모바일 세로 화면의 하이퍼캐주얼 액션 |
| 핵심 행동 | **맞춘다**(타격) + **피한다**(주루) |
| 소재 | 야구. 단, 야구 규칙을 재현하지 않고 **야구를 소재로 한 아케이드**로 만든다 |
| 시점 | 주자 뒤 **3인칭 러너 시점** |
| 개발 조건 | 약 3개월, 3명 (팀장 + 개발 경험이 적은 팀원 2명) |

**왜 이렇게?**

* 전작 「균형의 달인」이 물리·퍼즐·정적인 판단이었으니, 이번에는 **순간 반응과 액션**으로 확실히 다른 결을 낸다.
* 맞추기와 피하기는 억지로 붙인 두 행동이 아니라, **타격 → 주루라는 야구의 흐름**으로 자연스럽게 이어진다.
* 실제 야구 규칙(수비 AI, 볼/스트라이크, 주자 관리)을 넣으면 3개월·초보 팀원 조건에서 개발량이 감당되지 않는다.

---

## 2. 핵심 차별점 — 친 순간 결과가 정해지지 않는다

```text
일반 야구 게임 :  타격 → 결과 확정
이 게임        :  타격 → CHANCE(가능성) → 주루 회피 → 결과 확정
```

2루타 CHANCE를 얻었다면,

| 주루 | 최종 결과 |
| --- | --- |
| 잘 피해서 게이지를 채움 | 3루타로 올라감 |
| 무난하게 완주 | 2루타 그대로 |
| 실패가 많음 | 1루타로 떨어짐 |
| 한 구간을 통째로 실패 | 아웃 |

**왜 이렇게?**

* 팀장의 처음 아이디어다. "2루타급 공을 쳤어도 주루를 완벽히 하면 3루타, 못하면 1루타나 아웃."
* 플레이어는 "2루타 확보했네"가 아니라 **"여기서 잘하면 3루까지 간다!"** 라고 느낀다.
* 타격을 잘할수록 결과가 확정되는 게 아니라 **더 높은 상한선**을 얻는다.

### 이 게임이 노리는 감정

```text
공을 잘 쳤다 → "2루타 찬스!" → 달리기 시작 → 공이 날아온다, "어느 쪽이지?"
→ 성공! → 또 하나가 온다 → "이거 하나만 더 성공하면 3루다" → 욕심내서 도전
→ 3B! → "한 판만 더."
```

## 3. 게임 흐름

```text
한 타석 :  투구 → 타격 → CHANCE → 주루 → 결과
한 판   :  타석을 반복하다가 아웃 3개가 되면 게임 오버
```

* 타격 → CHANCE → 주루 → 결과 네 단계는 **어떤 경우에도 끊지 않는다.** 이 연결이 게임의 존재 이유다.

---

## 4. 조작 — 화면 4분할 터치

|  | 왼쪽 | 오른쪽 |
| --- | --- | --- |
| **위** | 좌상 | 우상 |
| **아래** | 좌하 | 우하 |

* 화면을 네 칸으로 나누고 **칸을 터치하는 것이 입력의 전부**다.
* 타격과 주루 모두 이 네 칸으로 조작한다.

**왜 이렇게?**

* 네 개의 버튼을 화면에 깔면 모바일 QTE 게임처럼 보인다. **화면 자체를 입력 영역**으로 쓴다.
* 타격과 주루가 같은 네 칸을 쓰니, 손이 하나의 체계만 익히면 된다.

---

## 5. 타격 — 언제 + 어디

* 공은 스트라이크존 **4칸 중 한 칸**으로 들어온다. 칸 배치는 화면 4분할과 같다.
* 공이 들어올 칸에 링이 뜨고, **링이 겹치는 순간** 그 칸을 친다.

| 타이밍 등급 | 시작 CHANCE |
| --- | --- |
| JUST (가장 정확) | 3B, 게이지를 더 채운 상태로 출발 |
| PERFECT | 3B |
| GREAT | 2B |
| GOOD | 1B |
| MISS (빗나감 · 스윙 안 함) | 아웃 |

| 누른 칸 (타이밍이 MISS가 아닐 때) | 결과 |
| --- | --- |
| 공이 온 칸 | 타이밍 등급 그대로 |
| 옆 칸 | 빗맞은 안타 — 무조건 1B |
| 대각선 반대 칸 | 파울 — 다시 던진다. 한 타석에 2번까지, 3번째는 아웃 |

**왜 이렇게?**

* 팀장 아이디어 "투수가 던진 공을 **조준해서** 맞힌다"를 **타이밍 + 코스** 두 축으로 옮겼다. 아무 데나 탭하는 방식은 쓰지 않는다.
* 타격은 **정확도와 타이밍**, 주루는 **반응 속도와 판단**. 두 파트가 서로 다른 실력을 요구한다.
* 타격으로는 최대 3B까지만 얻는다. **홈런은 주루로만** 만들 수 있다.

---

## 6. 주루 — 3인칭 러너

* 캐릭터는 **자동으로 달린다.** 플레이어는 이동하지 않고 **회피만** 한다.
* 주루는 **베이스 하나마다 한 구간**씩 끊어 달린다. CHANCE만큼 구간을 이어 달린다.
* 주루 중 CHANCE가 오르면 달릴 구간이 하나 늘어난다.
* 장애물은 멀리서 작게 나타나 점점 커지며 다가온다. 뒤 구간일수록 험하다.

```text
2B CHANCE :  홈 ──[구간]──▶ 1루 ──[구간]──▶ 2루 (끝)
```

**왜 이렇게?**

* 팀장이 원한 화면은 쿼터뷰가 아니라 **달려가는 주자의 시점에서 멀리서 날아오는 장애물을 피하는 장면**이다.
* 1인칭보다 3인칭이 **내 캐릭터가 보이고 어느 방향으로 피했는지 명확하며**, 주루하는 느낌도 강하다.
* 자유롭게 움직이게 하면 야구가 아니라 닷지 게임이 된다. **조작은 쉽게, 판단은 순간적으로.**
* 베이스마다 끊어 달려야 1루·2루를 지나 더 멀리 가는 과정이 눈에 보인다.

---

## 7. 회피 — 네 귀퉁이 동작

### 장애물

| 장애물 | 오는 곳 | 노리는 곳 |
| --- | --- | --- |
| **공** | 위쪽 좌·우 | 상체 |
| **수비수** | 아래쪽 좌·우 (태클) | 다리 |

### 정답 규칙 — 위는 반대쪽, 아래는 같은 쪽

| 위험 위치 | 눌러야 할 칸 | 캐릭터 동작 |
| --- | --- | --- |
| 좌상 (공) | **우상** | 오른쪽으로 몸을 기울여 피한다 |
| 우상 (공) | **좌상** | 왼쪽으로 몸을 기울여 피한다 |
| 좌하 (수비수) | **좌하** | 왼쪽 다리를 들어 넘긴다 |
| 우하 (수비수) | **우하** | 오른쪽 다리를 들어 넘긴다 |

### 판정

| 판정 | 조건 | 게이지 |
| --- | --- | --- |
| **PERFECT** | 정답 칸을 **충돌 직전**에 누름 | 크게 오름 |
| **NICE** | 정답 칸을 그보다 일찍 누름 | 오름 |
| **WRONG** | 다른 칸을 누름 | 줄어듦 |
| **TOO LATE** | 끝까지 안 누르고 충돌 | 더 크게 줄어듦 |

* 장애물은 충분히 가까워진 뒤부터 입력을 받는다. 그 전의 입력은 감점 없이 무시한다.
* 장애물 하나에 입력은 한 번만 받는다.

**왜 이렇게?**

* 팀장 아이디어다. 야구 주로는 좁으니 레인을 옮기는 대신 **위험이 오는 위치에 맞는 동작**을 한다.
  "왼쪽 위에서 공 → 오른쪽 위를 눌러 머리를 기울인다", "오른쪽 아래에서 1루수가 달려든다 → 오른쪽 아래를 눌러 발을 든다."
* 3레인은 레인만 보고 움직이면 돼서 너무 쉽다. 이 방식은 **위험 위치 + 위험 종류 + 맞는 동작**을 동시에 판단해야 한다.
* 위와 아래의 규칙이 다른 것은 **일부러 넣은 혼란 요소**다.
* **충돌 직전이 최고 판정**이어야 눈에 보이는 충돌 순간과 판정이 맞아 손이 납득한다.
* 무반응이 오답보다 더 손해다. **틀리더라도 반응하는 편이 낫게** 만든다.

## 8. 런 게이지 — "조금만 더"를 눈에 보이게

* 0~100이고 **50에서 시작**한다.
* 회피에 성공하면 차고 실패하면 줄어든다. **연속으로 성공할수록 더 많이 찬다.**
* **100에 닿으면 CHANCE 한 단계 상승**, **0 아래로 가면 한 단계 하락**한다.
* **3B부터는 차는 양이 절반**이다. 감점은 그대로다.
* HR이 된 뒤에도 실패하면 다시 떨어질 수 있다.
* 게이지와 연속 기록은 한 타석 안에서 구간이 바뀌어도 이어진다.

**왜 이렇게?**

* 성공 횟수를 세는 방식보다, 게이지가 차오르는 걸 보면서 **"조금만 더 하면 3루 간다"** 는 목표를 계속 갖게 된다.
* 3B부터 절반만 차게 해서 **3B에서 홈런을 노리는 것이 도박**이 되게 한다. 홈런은 특별한 결과로 남긴다.

---

## 9. 결과와 아웃

* **최종 결과는 CHANCE가 아니라 실제로 밟은 베이스**다.
* **한 구간에서 장애물을 하나도 못 피하면** 그 베이스 앞에서 아웃이다.
* CHANCE가 떨어져서 **이미 밟은 베이스 이하**가 되면 그 자리에서 멈추고, 밟은 베이스가 결과가 된다.
* 아웃되면 긴 연출 없이 바로 결과로 넘어간다.

| 결과 | 1B | 2B | 3B | HR | 아웃 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 점수 | 100 | 200 | 350 | 600 | 0 |

**왜 이렇게?**

* 베이스는 공짜로 밟을 수 없어야 CHANCE 하락과 실패에 무게가 생긴다.
* 결과 화면의 핵심은 점수가 아니라 **"타격으로 만든 가능성을 주루로 얼마나 끌어올렸는가"** (예: 2B → 3B)다.

---

## 10. 난이도와 운

* 타석이 진행될수록 레벨이 오른다 (Lv.1~4). **레벨은 주루 길이가 아니라 밀도(속도·대응 시간·간격)만** 올린다.
* **Lv.1은 학습 단계**다. 공만 나오고, 눌러야 할 칸을 화살표로 알려준다. 수비수는 다음 레벨부터 나온다.
* 장애물은 **패턴(장애물 묶음) + 난이도 예산 + 확률 뽑기**로 만든다.
  * 패턴마다 난이도 점수가 있다 (쉬움 1 / 보통 2 / 어려움 3).
  * 구간마다 쓸 수 있는 점수 안에서 패턴을 뽑는다.
  * 레벨이 높을수록, 뒤 구간일수록 어려운 패턴이 뽑힐 확률이 커진다.

**왜 이렇게?**

* 팀장의 요구다. **실력 요소만으로는 너무 쉽고, 운 요소가 있어야 난이도를 조절**할 수 있다.
* 목표 비율은 **실력 70 / 운 30**. 운이 너무 크면 "잘해도 못 깬다", 실력만 있으면 "패턴 외우면 끝"이 된다.
* **운은 상황을 정하고, 실력은 상황을 해결한다.** 매번 순서는 달라지지만, 너무 쉬운 판이나 말도 안 되게 어려운 판은 예산으로 막는다.

## 11. 설계 원칙

| 원칙 | 뜻 |
| --- | --- |
| **나쁜 랜덤은 버그** | 화면 밖에서 갑자기 등장, 너무 짧은 대응 시간, 두 개를 동시에 처리해야 하는 상황, 입력으로 풀 수 없는 상황은 만들지 않는다 |
| **실패 이유가 보여야 한다** | 틀리면 잘못 누른 쪽으로 실제로 피한 뒤 맞고, 정답을 알려준다. "왜 맞았지?"가 나오면 조작 체계가 실패한 것이다 |
| **한 번에 하나씩** | 네 방향에서 쏟아지면 야구가 아니라 탄막 게임이 된다 |
| **실패는 짧게** | 아웃 후 곧바로 결과로 간다 |

## 12. 프로토타입이 확인할 것

가장 중요한 질문은 **"4방향 대응 주루가 정말 손맛 있고 반복하고 싶은가?"** 다. 그래서 **타격보다 주루 검증이 먼저**다.

"작동한다"는 성공 기준이 아니다. 아래 질문에 YES가 나와야 한다.

| # | 질문 |
| --- | --- |
| Q1 | 첫 플레이 30초 안에 조작법을 이해하는가? |
| Q2 | 장애물이 다가올 때 긴장하는가? |
| Q3 | 회피 성공 후 쾌감이 있는가? |
| Q4 | "한 번만 더"라는 느낌이 드는가? |
| **Q5** | **2B CHANCE가 3B가 될 것 같을 때 욕심이 생기는가?** ← 가장 중요 |
| Q6 | 실패했을 때 "억울하다"가 아니라 "내가 더 잘했으면"이라고 느끼는가? |

## 14. 한 타석 예시

| 순서 | 상황 | 결과 |
| --- | --- | --- |
| 1 | 우상 칸으로 오는 공을 링이 겹칠 때 조금 늦게 우상 터치 | GREAT → **2B CHANCE** |
| 2 | [홈→1루] 좌상에서 공 → 우상 입력, 충돌 직전 | PERFECT, 게이지 크게 오름 |
| 3 | 1루 통과. [1루→2루] 좌하에서 수비수 → 좌하 입력, 충돌 직전 | PERFECT 연속, 게이지 가득 → **3B CHANCE** |
| 4 | 우상에서 공 → 좌상 입력, 조금 일찍 | NICE, 3B라서 게이지는 조금만 오름 |
